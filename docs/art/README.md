# Artwork provenance
Two original illustrations were generated for Hauntkit on November 5, 2026 using OpenAI image generation.
The prompts are recorded verbatim in PROMPTS.json.

- originals/inn.png: warm seaside Ghost Inn exterior, 1536 × 1024.

The web build uses WebP format conversions under site/assets. Original PNGs remain here.
