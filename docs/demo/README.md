# The 92-second walkthrough

Watch the uploaded unlisted version:
https://www.youtube.com/watch?v=hf8rdYMLEh8 . It is accessible by link without a
password. YouTube displays 1:33 in its Studio list and 1:32 in the watch player;
the checked local master is exactly 92 seconds.

`python3 docs/demo/render.py` reconstructs the picture edit and combines it with
the checked-in lossless final audio mix. FFmpeg must be installed. Output goes
to the ignored `docs/demo/output/` directory. Encoders may vary by FFmpeg version.

`frames/` contains public crops of actual application renders, operated and
captured in Chrome. Browser chrome, personal tabs and registration pages are
excluded. This is an edited walkthrough of real states, not continuous footage.
The project itself remains fully interactive.

`score.py` regenerates the original 78-BPM waveform score and three sound effects
using Python's standard library. The final mix in `master.flac` includes nine
effect cues, smooth music ducking, loudness normalization and stereo output.
No external recording or reference-video audio is included. Music and effects
are part of the project's MIT-licensed original work.

`plan.json` and `DIRECTION.md` document the edit and product-derived direction.
Paths under `original-audio/` are generated by `score.py`; the picture renderer
uses the checked-in `master.flac` final mix directly.
`mcp-receipt.json` is the output of actual SDK → stdio server → world calls,
using synthetic example text. It is not a Kiro-agent playthrough.

Verification: H.264/AAC, 1920×1080, 30fps, exactly 92 seconds; the final MP4's
2fps contact sheet, all eight cut strips and the dense save-control frame were
visually inspected. Measured final audio peak −1.3dBFS, mean −18.5dBFS. The
audio was not human-listened; those measurements are not a listening review.

Kiro quota ended the initial file-writing run; the video does not claim a Kiro
MCP playthrough or live model generation in the browser.
