# Hauntkit

A new Kiroween 2026 Skeleton Crew project. A small reusable JavaScript foundation
for character applications and two complete examples: Ghost Inn (exploration) and
Lost Letters (guided writing). Warm, peculiar, kind, and useful.

The browser examples work without an account or API key. Built-in dialogue and
letter drafting are authored, deterministic story mode. Never label them as live
model output. Real AI agents use the same worlds through MCP. Narration is not
authoritative state.

Use ES modules, Node >=20, browser-native HTML/CSS/JS, and the official MCP SDK for
stdio. Two apps in separate folders. Shared engine owns sessions, versions, atomic
actions and public observations. Each world owns business rules; no generic DSL.

Never import private user data, family-workspace code, credentials, or other
projects' assets. No production services. Test on this Mac. No publishing or
cloud resources from a builder agent. All user strings are text, not HTML or
executable instructions. Never expose hidden game state to a narrator.
